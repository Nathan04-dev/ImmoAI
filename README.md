# 🏠 KI-Immobilien-Preisschätzer

Eine einfache Web-Anwendung zur Schätzung von Immobilienpreisen basierend auf Machine Learning. Das Modell nutzt den bekannten Kaggle House Prices Datensatz.

## 🛠️ Tech Stack
* **Python**
* **XGBoost**
* **Pandas**
